## 2. Data we process

The bot only receives data from Discord when it is on a server and someone uses one of
its commands or buttons. It does **not** read or store the content of your messages, and
it does not request Discord's message content, members or presence data.

**Data about you as a player** (stored when you use the bot):

| Data | Purpose |
| --- | --- |
| Discord user ID | Recognising your game account |
| Discord username | Showing you on leaderboards |
| Game statistics (builds, bricks, completed floors, active days, first and last build time) | Running the game, profile, leaderboards |
| Build log (time, amount and result of each build, per server) | Game history, preventing duplicate actions, fair play |
| Coins and coin transactions | In-game currency |
| Achievements, badges and visitor photos | Collections and profile |
| Daily reward claims and streak | Daily reward |

**Data about a server** (stored when the bot is added or a tower is created):

| Data | Purpose |
| --- | --- |
| Server ID, server name, server owner's user ID, date the bot was added or removed | Assigning the tower and settings to the server |
| Tower name, design, height, progress and other game state | Running the game |
| IDs of the channel and message that show the tower | Updating the tower message |
| Notification settings (channel ID, role IDs, on/off switches) | Sending notifications as configured |
| User IDs of the most recent builders and of the tower's creator | Game rules ("take turns") and display |

**Data used only for a moment and not stored:**

- Your account creation date and the date you joined the server – checked on each build
  to prevent abuse through new or secondary accounts.
- Your avatar – downloaded from Discord to draw your profile card, then discarded.
- Your display name – shown on your profile card and album.

**Log files:** The bot writes technical logs (errors, start and stop, server IDs). They
can contain server IDs and, in error cases, user IDs. Log files are rotated and
overwritten automatically (at most about 30 MB in total).

We do not use cookies, tracking or advertising, and we do not create profiles for
purposes other than the game.

## 3. Legal bases

- **Art. 6(1)(b) GDPR** – processing is necessary to provide the game you asked for by
  using the bot (performance of the Terms of Service).
- **Art. 6(1)(f) GDPR** – our legitimate interest in running the bot securely, preventing
  abuse and cheating, and fixing errors (anti-abuse checks, build log, log files).

## 4. Where the data is stored and who receives it

- The bot and its database run on a server in **Germany** rented from
  [NAME OF YOUR HOSTING PROVIDER, CITY, COUNTRY], which processes data on our behalf.
- **Discord** (Discord Netherlands B.V. / Discord Inc.) necessarily processes everything
  the bot sends and receives. Discord's own privacy policy applies to that:
  <https://discord.com/privacy>.

We do not sell your data and do not pass it on to anyone else, unless we are legally
obliged to.

Tower names, tower heights and usernames with game statistics appear on **global
leaderboards** that users on other servers can see. Your profile, album and statistics
can be viewed by other members of servers you share with the bot.

## 5. How long we keep data

- Game data is kept as long as you or your server use the bot.
- If the bot is removed from a server, that server's tower and statistics are kept so
  that the game can continue if the bot is added again. A server owner can ask us to
  delete them.
- You can ask us to delete your personal game data at any time (section 6). We delete it
  within 30 days. Entries may then show as an unknown user or disappear from leaderboards.
- Log files are overwritten automatically as described above.

## 6. Your rights

Under the GDPR you have the right to:

- **access** the data we hold about you (Art. 15);
- **rectification** of incorrect data (Art. 16);
- **erasure** of your data (Art. 17);
- **restriction** of processing (Art. 18);
- **data portability** (Art. 20);
- **object** to processing based on legitimate interests (Art. 21).

To use any of these rights (access, deletion and so on), open a request on our support
server <https://discord.gg/NrK3KZ9DPM> or write to vulpobot@gmail.com. Include your Discord user
ID so we can find your data. We may ask you to confirm that the account is yours, for
example by sending a message from it.

You also have the right to lodge a complaint with a data protection supervisory
authority, for example the one responsible for your place of residence or for us:
Der Landesbeauftragte für den Datenschutz Niedersachsen (State Commissioner for Data
Protection of Lower Saxony), Hannover, <https://www.lfd.niedersachsen.de>.

## 7. Security

Access to the database is restricted to the bot. The database is only reachable from
the server itself, access is password-protected, and the bot's access data is stored
separately from its code.

## 8. Children

The bot is not directed at children below the minimum age Discord requires in their
country. We do not knowingly process data of such children.
